# Security Policy

## Supported Versions

Only the latest version on the `main` branch and the latest published deployment receive security fixes.

## Reporting a Vulnerability

Please use [GitHub private vulnerability reporting](https://github.com/colin-110/papercut/security/advisories/new) when available. If it is unavailable, contact the repository owner privately through GitHub before opening an issue.

Include a clear description, reproduction steps, affected browser and version or commit, and possible privacy or security impact.

Do not include real private documents, credentials, access tokens, or personal data. Please allow reasonable time for investigation and a fix before public disclosure.

## Privacy-Specific Concerns

Report any behavior that uploads file bytes, exposes file contents to a third party, leaks object URLs, or records filenames or document metadata unexpectedly as a security issue.
